# Set up a delivery profile

## Goal
Create a delivery profile: choose the days you deliver, set the order cut-off, and
block any dates you can't deliver.

## Concept
A delivery profile is a delivery schedule you share across a group of customers: the
weekdays you deliver, one-off dates you add or block, and an order cut-off for each
delivery day. Each customer is on one profile. When they order, the only delivery dates
they can choose are their profile's dates whose cut-off hasn't passed, and a customer
with no profile has no dates to choose at all. Getting it right means customers can't
book a delivery you can't make, and you always get the notice you need to prepare it.

## Starting data
- No delivery profiles exist (nothing beyond the base)

## Steps
1. Start a new delivery profile called Western Suburbs
2. Choose Tuesday and Thursday as the default delivery days
3. Set the order cut-off to 16:00, 1 processing day before delivery
4. Block a Thursday next month as a specially disabled date (optional)
5. Create the profile

## Done when
Western Suburbs appears in the delivery profiles list as active, delivering Tuesday
and Thursday.

## Doc notes
- Audience: distributor owner
- Mention: deactivating a profile leaves its customers with no delivery dates
- Mention: a cut-off can be different for a particular weekday (as Standard Weekday does on Fridays)
