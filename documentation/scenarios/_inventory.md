### Integrations (accounting)
Owner can do everything here; Operations manager can sync, link and import but not connect,
disconnect or change Settings. Every Xero scenario starts connected to Xero's Demo Company
(UK) through the saved docs connection (`withXero` seeds), with the Xero side put into a
known state first (`pnpm docs:xero-data`, spec in `scenarios/xero-fixtures.ts`).

| Task | Scenario | Notes |
|---|---|---|
| Connect Xero | connect-xero | Parked: needs a person to sign in to Xero over the HTTPS entry point |
| Sync with Xero (first sync) | sync-with-xero | Starts connected, never synced; Concept gives the automatic sync intervals |
| Match your tax types to Xero | match-tax-types-to-xero | Name-only matching; "Standard VAT" vs "20% (VAT on Income)" gets no suggestion |
| Create a tax type from a Xero tax rate | import-xero-tax-rate | Xero's 5% (VAT on Income) → Reduced VAT |
| Match your products to Xero | match-products-to-xero | SKU suggestion + match by hand |
| Import a product from Xero | import-product-from-xero | Creates a Draft; tax type set only if the Xero rate is linked |
| Import several products from Xero at once | bulk-import-products-from-xero | Honour suggested matches is off by default (duplicates); import report |
| Match your customers to Xero | match-customers-to-xero | Email and account-number suggestions + match by hand; link is mandatory for invoices |
| Add a customer from a Xero contact | import-customer-from-xero | Only contacts Xero treats as customers |
| Import several customers from Xero at once | bulk-import-customers-from-xero | Same report as products |
| Link a product from its own page | link-product-from-its-record | Product's Integrations tab; also shows the link once made |
| Link a customer from its own page | link-customer-from-its-record | Customer's Integrations tab; warns until linked |
| Review a change made in Xero | review-a-xero-change | "Changed in Xero" + Acknowledge; Stocdup's price never changes |
| Choose how invoices are created in Xero | xero-invoice-settings | Draft / Submitted for approval / Authorised, default sales account (ADR-079) |
| Send an order's invoice to Xero | invoice-sent-to-xero | Accept → invoice in Xero; Invoice & payment on the order after a sync |
| Disconnect Xero | — | Links kept if you reconnect the same organisation; needs connect-xero to undo |
