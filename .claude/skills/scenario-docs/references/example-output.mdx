Different areas get deliveries on different days, with different order deadlines. A
delivery profile sets both, and applies to every customer assigned to it.

## Before you start

- You'll need an owner account.
- You'll need at least one customer.

## 1. Start a new profile

Go to **Delivery Profiles** (1) and select **New profile** (2).

![The delivery profiles list with the New profile button](./img/delivery-profile-setup/start-a-new-profile.png)

## 2. Name it and choose delivery days

In **Name** (1), enter **Western Suburbs**. Under **Default delivery days** (2), select
**Tue** and **Thu**.

![The new profile form with Tuesday and Thursday selected](./img/delivery-profile-setup/name-it-and-choose-delivery-days.png)

## 3. Set the order cut-off

Set **Cut-off time** to **16:00** and **Processing days before delivery** to **1**.

This is the ordering deadline for every delivery day that doesn't have its own override.

## 4. Create the profile

Select **Create profile**. The profile's edit page opens.

:::note

Per-day overrides only appear once the profile has been created.

:::

## 5. Override the cut-off for one day (optional)

Add an override for **Tuesday** (1): order by **12:00**, **2** processing days before.

![The Tuesday override row in the profile](./img/delivery-profile-setup/override-the-cut-off-for-one-day.png)

## 6. Block a date (optional)

In the calendar (1), mark a Thursday next month as specially disabled, then select
**Save**. The legend (2) shows what each date colour means.

![The calendar with a blocked Thursday and its legend](./img/delivery-profile-setup/block-a-date.png)

:::note

On a default delivery day, the first click marks the date as specially enabled, and the
second click marks it as specially disabled.

:::

## Result

**Western Suburbs** appears in the delivery profiles list as **Active**, delivering on
**Tue, Thu**, with **0** customers (1). Customers you assign to it can only choose the
delivery dates it allows.

![The Western Suburbs row in the delivery profiles list](./img/delivery-profile-setup/done.png)

:::warning

If you delete a profile, its customers are left with no delivery dates.

:::
